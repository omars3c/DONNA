# 🧠 D.O.N.N.A. (Stark OS) — Полное архитектурное руководство

> **D.O.N.N.A.** (*Digital Online Neural Network Assistant*) — персональный тактический ИИ-ассистент, вдохновлённый системой **FRIDAY / JARVIS** Тони Старка (Stark Industries). 
> Система объединяет полнодуплексное голосовое общение в реальном времени, тактический кибернетический интерфейс, оффлайн-распознавание ключевых слов, векторную семантическую память (Cortex), автономных веб-агентов на Chromium и глубокий контроль операционной системы Windows.

## 2. Ключевые подсистемы и модули

### 🎙️ 1. Голосовой пайплайн и звук
* **Live WebSocket Full-Duplex (`main.py`)**:
  * Прямой аудио-стриминг через `google-genai` Live API (`models/gemini-2.5-flash-native-audio-preview-12-2025` / `gemini-2.0-flash`).
  * Входящий микрофонный поток: **16 кГц Mono PCM** (нарезка по ~50 мс).
  * Исходящий голос Донны: **24 кГц High-Fidelity Audio** (голос *Kore* / *Svetlana*).
* **Оффлайн Wake Word (`core/wakeword.py`)**:
  * Локальная модель **Vosk (Kaldi)**: 0 мс сетевой задержки.
  * Реагирует на: *«Донна», «Дон», «Данна», «Пятница», «Фрайдей», «Джарвис»*.
* **Голосовое прерывание (Voice Barge-In / «Донна, стоп»)**:
  * Во время речи Донны микрофон не отключается, а слушает стоп-слова (*«стоп», «донна стоп», «хватит», «молчи», «тихо»*).
  * При обнаружении стоп-фразы буфер аудио немедленно очищается, воспроизведение обрывается за миллисекунды, а Донна сразу переходит в режим ожидания следующей команды.
* **RMS VAD (Voice Activity Detection)**:
  * Анализирует громкость голоса: пока вы говорите в микрофон, таймер Донны непрерывно продлевается, предотвращая случайное засыпание посреди длинного предложения.
* **Stark SFX Pack (`core/sfx.py`)**:
  * Аутентичные звуковые эффекты Stark Industries на активацию, подтверждение действий, запуск и ошибки.

### 🖥️ 2. Тактический интерфейс (Tactical HUD)
Файл: [`ui.py`](file:///c:/fryday%20v1/wassupbeijing/ui.py)
* **60 FPS Tactical Sphere Canvas**:
  * Векторная 3D-сфера с вращающимися орбитальными кольцами, радаром, звуковыми волнами и реакцией на наведение мыши и клики.
  * Цветовая индикация состояний:
    * 🟡 **STANDBY** (Ожидание) — янтарное свечение.
    * 🟢 **LISTENING** (Слушает) — изумрудно-зеленый пульс.
    * 🟡 **THINKING** (Обработка/Поиск) — золотое сканирование.
    * 🟡 **SPEAKING** (Говорит) — аудио-волны реактора.
    * 🔴 **MUTED** (Микрофон выключен) — алый индикатор.
* **Аппаратная телеметрия в реальном времени**:
  * Мониторинг нагрузки: **CPU %**, **RAM %**, **GPU %** (через NVML), **Сетевая скорость (↑ Mb/s, ↓ Mb/s)**, **Температура (°C)**.
* **Динамические цветовые палитры (Theme Engine)**:
  * *Amber Gold (Friday)*, *Stark Cyan*, *Arc Reactor Blue*, *Emerald Tactical*, *Crimson Combat*, *Amethyst Core*, *Solar Flare*.
* **Интерактивные панели**:
  * Выдвижной ящик контента (Content Panel) для отображения новостей, отчётов и результатов поиска.
  * Видео-окно камеры, терминал логов с цветными префиксами и поле ввода текстовых команд.

### 🧠 3. Семантическая векторная память (Cortex System)
Файлы: [`memory/cortex_engine.py`](file:///c:/fryday%20v1/wassupbeijing/memory/cortex_engine.py), [`actions/cortex_memory.py`](file:///c:/fryday%20v1/wassupbeijing/actions/cortex_memory.py)
* **Векторная база данных SQLite (`memory/cortex.db`)**:
  * Хранение знаний, заметок, идей, целей, фактов и дневника с **3072-мерными векторными эмбеддингами** (`models/gemini-embedding-001` + локальный N-gram/TF-IDF фоллбэк).
* **Гибридный семантический поиск (`recall_memory`)**:
  * Ищет записи по смыслу вопроса, даже если слова не совпадают буквально (формула: 70% векторный косинус + 20% лексика + 10% важность).
* **Умный Task & To-Do Tracker (`manage_cortex_tasks`)**:
  * Создание, просмотр, завершение и удаление задач.
  * Приоритеты (*low*, *normal*, *high*, *critical*), дедлайны, привязка к проектам.
  * Автоматическая инъекция активных задач в системный промпт при старте сессии.
* **Эпизодический дневник (`log_journal`)**:
  * Сохранение итогов дня, мыслей и ключевых событий.

### 🌐 5. Автономный агент (Auto-GPT / Chromium / Word docx)
Файлы: [`actions/agent_task.py`](file:///c:/fryday%20v1/wassupbeijing/actions/agent_task.py), [`actions/web_search.py`](file:///c:/fryday%20v1/wassupbeijing/actions/web_search.py)
* **Автономные цепочки действий (`agent_task`)**:
  * Полный цикл: веб-поиск → глубокий парсинг страниц через **Chromium Playwright** (выполняет JavaScript) → синтез выжимки → генерация форматированного документа Microsoft Word (`.docx`) или `.pdf` → автоматическое открытие готового файла на экране.
  * Вызывается **только при явной просьбе сохранить/сделать файл** (для обычных устных вопросов Донна отвечает голосом через `web_search`).
* **Устойчивый веб-поиск (`web_search`)**:
  * Режимы: `news` (свежие новости), `research` (анализ), `price` (цены).
  * Автоматический fallback на DuckDuckGo при исчерпании квоты Gemini Search.

### 📡 7. Фоновый мониторинг новостей и телеметрия
Файлы: [`actions/background_monitor.py`](file:///c:/fryday%20v1/wassupbeijing/actions/background_monitor.py), [`actions/system_monitor.py`](file:///c:/fryday%20v1/wassupbeijing/actions/system_monitor.py), [`actions/proactive.py`](file:///c:/fryday%20v1/wassupbeijing/actions/proactive.py)
* **Фоновый трекер тем (`background_monitor`)**:
  * Проверяет интересные темы (например, *«новости ИИ»*) в фоне.
  * Фильтрует заглушки агрегаторов и сохраняет полную смысловую выжимку: когда выходит новость, Донна кратко сообщает заголовок, а при вопросе *«Что за новость?»* сразу выдаёт подробности.
* **Аппаратный монитор (`system_monitor`)**:
  * Отслеживает критический перегрев или перегрузку CPU/RAM (>90%) и предупреждает с ограничением частоты (cooldown).
* **Проактивный режим (`proactive`)**:
  * Если пользователь долго молчит, Донна может сделать ненавязчивый полезный чекин с учётом времени суток и открытых задач.

## 4. Маршрутизация инструментов (Tool Declarations)

Донна использует **строгое разделение ответственности** между инструментами:

| Инструмент | Когда вызывается | Что делает |
|---|---|---|
| `recall_memory` | Вопросы о прошлых заметках, проектах, идеях, планах | Выполняет семантический поиск по смыслу в базе Cortex |
| `save_knowledge` | Просьба сохранить мысль, заметку, факт, идею | Сохраняет в Cortex с векторным эмбеддингом |
| `manage_cortex_tasks` | Создание, просмотр, закрытие задач и to-do | Управляет списком задач с приоритетами и дедлайнами |
| `log_journal` | Запись мыслей или итогов дня | Заносит запись в личный дневник Cortex |
| `web_search` | Вопросы о новостях, трендах, фактах, ценах | Ищет информацию и отвечает **устно голосом** |
| `agent_task` | Явная просьба **«сохрани в Word / сделай файл / отчёт»** | Собирает данные через Chromium и генерирует `.docx` файл |
| `open_app` | *«Открой [название программы]»* | Запускает локальное приложение Windows |
| `computer_control` | Кликнуть, напечатать текст на экране, нажать клавиши | Выполняет клики и вставляет текст через буфер |
| `computer_settings` | Громкость, яркость, закрытие окон, Wi-Fi | Регулирует системные параметры Windows |
| `screen_process` | *«Посмотри на экран / что там?»* | Делает скриншот и анализирует изображение |
| `manage_monitor` | Добавить/удалить тему для фонового отслеживания | Ставит тему на фоновый мониторинг |

## 5. Шпаргалка голосовых команд

### 🎙️ Управление речью и диалогом
* **«Донна»** / **«Пятница»** — пробуждение из режима ожидания.
* **«Донна, стоп»** / **«Стоп»** / **«Хватит»** / **«Молчи»** — моментально прерывает речь Донны и переводит в режим слушания.
* **«Спасибо, отбой»** / **«Спи»** — переводит Донну в режим ожидания (Standby).

### 🧠 Память и Задачи (Cortex)
* *«Донна, что мы планировали по проекту Stark OS?»*
* *«Донна, найди в моих заметках всё про экзамен»*
* *«Донна, добавь задачу: подготовить релиз к пятнице с высоким приоритетом»*
* *«Донна, какие у меня открытые задачи на сегодня?»*
* *«Донна, отметь задачу номер 1 как выполненную»*
* *«Донна, запиши в дневник: сегодня завершили архитектуру векторной памяти»*

### 🌐 Новости и Исследования
* *«Донна, какие последние новости в мире искусственного интеллекта?»* (ответит устно)
* *«Донна, найди статьи про квантовые процессоры, сделай выжимку на 1 страницу и сохрани в Word»* (создаст и откроет `.docx`)

## 6. Установка и запуск

### Требования
* **ОС**: Windows 10/11 (64-bit)
* **Python**: 3.10 – 3.14
* **Микрофон и динамики**: Активны по умолчанию

### Установка зависимостей
```powershell
pip install -r requirements.txt
playwright install chromium
```

### Настройка API-ключей
Убедитесь, что в файле `config/api_keys.json` указан ваш Gemini API ключ:
```json
{
  "gemini_api_key": "ВАШ_GEMINI_API_KEY",
  "assistant_name": "Донна",
  "ui_color": "amber"
}
```

### Запуск
```powershell
python main.py
```
