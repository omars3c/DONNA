## 1. Обзор архитектуры (Pure Microservices)

Проект полностью функционирует на **чистой распределённой архитектуре микросервисов**.
Единой точкой входа и оркестрации процессов является **`run_microservices.py`**.

Все 8 сервисов запускаются как изолированные процессы, взаимодействуют по **HTTP REST** и **WebSocket**, защищены межсервисными токенами `X-Donna-Internal-Token`, строгим белым списком CORS, и рапортуют о сбоях в локальный монитор **Sentinel** (:8006) и **Sentry**.

```
         ┌───────────────────┬──────────────────────┼──────────────────┬───────────────────┐
         ▼                   ▼                      ▼                  ▼                   ▼
┌─────────────────┐ ┌─────────────────┐ ┌──────────────────────┐ ┌─────────────────────┐ ┌─────────────────┐
│ Sentinel (:8006)│ │ Cortex  (:8002) │ │ Research Agent(:8003)│ │ Win Host  (:8004)   │ │ Gateway (:8000) │
```

## 2. Спецификация микросервисов

| Порт | Сервис | Модуль запуска | Назначение и ключевые функции |
| :--- | :--- | :--- | :--- |
| **8006** | **Sentinel Service** | `services.sentinel_service.app` | **Телеметрия и трекинг ошибок.** Запускается первым. Принимает батчи ошибок со всех сервисов по токену, дедуплицирует логи, сохраняет в SQLite (`memory/sentinel.db`) и проксирует в Sentry. |
| **8002** | **Cortex Memory Service** | `services.cortex_memory_service.app` | **Долговременная память и RAG.** Семантический поиск по эмбеддингам, управление задачами, факты о пользователе, ежедневный журнал. БД работает в высокопроизводительном режиме **SQLite WAL** (Write-Ahead Logging). |
| **8003** | **Research Agent Service** | `services.research_agent_service.app` | **Интеллектуальный веб-ресёрч и генерация документов.** Автономный поиск через Gemini Flash с каскадным переключением на DuckDuckGo/Wikipedia. Создание профессиональных отчётов Word (.docx) и PDF, анализ YouTube. |
| **8004** | **Windows Host Agent** | `services.windows_host_agent.app` | **Аппаратный агент ОС Windows.** Управление окнами, клики мыши, клавиатура (`pyautogui`), запуск приложений без риска shell injection, планировщик задач Windows (`reminder`), управление браузерами (`browser_control`), телеметрия CPU/RAM/GPU. |
| **8000** | **Channel Gateway Service** | `services.channel_gateway_service.app` | **Внешние каналы и веб-интерфейсы.** Мобильный пульт управления, спаривание устройств по QR/OTP, Telegram Bot Bridge, RSS-монитор и встроенный веб-интерфейс **React Tactical HUD** (`/hud`). |
| **8001** | **Brain Orchestrator** | `services.brain_orchestrator.app` | **Ядро интеллекта.** Двусторонний потоковый аудио-сокет с **Gemini Live**, диспетчеризация 17 инструментов (`TOOL_DECLARATIONS`), координация состояний (STANDBY, LISTENING, THINKING, SPEAKING). |
| **8005** | **Audio Stream Service** *(опц.)* | `services.audio_stream_service.app` | **Аудио-драйвер.** Захват микрофона (16 кГц PCM), оффлайн-распознавание фразы активации через **Vosk**, воспроизведение ответов через динамики (24 кГц). |
| **8007** | **Autonomous Agent Service** | `services.autonomous_agent.app` | **Автономный ReAct-агент.** Многошаговый цикл решения инженерных задач (Thought → Action → Observation). Автоматические повторы при сбоях API, каскадный пул моделей (`gemini-3.5-flash` / `gemini-3.6-flash`), защита от prompt injection. |

## 4. Архитектурная безопасность (Hardened)

1. **Межсервисная авторизация (`X-Donna-Internal-Token`)**:
   - При старте оркестратор `run_microservices.py` генерирует криптографически стойкий 256-битный токен и передаёт его через переменную окружения `DONNA_INTERNAL_TOKEN`.
   - Все микросервисы проверяют входящие запросы через middleware `verify_internal_token`. Прямые несанкционированные вызовы из локальной сети блокируются с кодом `403 Forbidden`.
2. **CORS и веб-безопасность**:
   - Запрещены подстановочные знаки `*`. Разрешены только доверенные порты локального шлюза (:8000) и интерфейсов (:3000, :5173).
3. **Безопасность файловых загрузок**:
   - Все загружаемые в дашборде файлы исполняемых форматов (`.exe`, `.bat`, `.cmd`, `.ps1`, `.vbs` и др.) автоматически суффиксируются расширением `.download`, предотвращая случайное исполнение.
4. **Защита спаривания Telegram**:
   - Перехват управления ботом третьими лицами исключён: спаривание требует ввода одноразового 6-значного OTP-кода (`/pair <OTP>`), генерируемого в консоли хоста.
5. **Защита ReAct от непрямых Prompt Injection**:
   - Входные данные веб-страниц и внешних файлов изолированы как `<UNTRUSTED EXTERNAL DATA>`.
   - Инструментальный диспетчер блокирует попытки деструктивных команд (форматирование дисков, очистка системных каталогов, правка реестра).

## 5. Пользовательские интерфейсы (UI)

D.O.N.N.A. поддерживает два типа пользовательских интерфейсов:
1. **PyQt6 Tactical Desktop HUD**:
   - Запуск: `python run_microservices.py --with-ui`.
   - Нативный полупрозрачный тактический оверлей на рабочем столе Windows с анимацией радара, звуковой волны и виджетом статуса системы.
2. **React Tactical Web HUD**:
   - Доступен в браузере по адресу: **`http://127.0.0.1:8000/hud`**.
   - Собран на React 19, Vite и Tailwind CSS.
   - Подключается к WebSocket `ws://127.0.0.1:8001/ws/hud` и позволяет вводить команды текстом с любого монитора, ноутбука или планшета в локальной сети.

```bash
# Полный запуск всех микросервисов:
python run_microservices.py

# Запуск с PyQt6 интерфейсом:
python run_microservices.py --with-ui

# Запуск без микрофона (серверный режим):
python run_microservices.py --no-audio

# Запуск тестов безопасности и контрактов:
python scratch/test_security_and_contracts.py

# Запуск тестов 17 инструментов:
python scratch/test_phase4_tools.py

# Полный сквозной тест микросервисов (24 проверки):
python scratch/test_microservices_e2e.py
```
